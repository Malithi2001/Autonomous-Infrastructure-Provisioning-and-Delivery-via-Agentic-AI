# Final Report Screenshot Checklist

Use this folder to organize screenshot evidence for the final report and demo presentation. Do not store secrets, tokens, private repository settings, or sensitive environment values in screenshots.

Required screenshots:

1. Login page
2. Dashboard
3. Multi-Agent Orchestration page
4. Agent Trace for "show running containers"
5. Diagnosis page with npm error prediction
6. Repository Setup page with detected stack
7. GitHub workflow PR
8. GitHub Actions failed run
9. Workflow Failures page
10. Fix PR or approval request
11. Audit log page
12. Evaluation Dashboard
13. Model confusion matrix
